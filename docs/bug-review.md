# Demo 复查记录

本次检查范围：HTTP 网关、主机请求、会话回收、启动脚本、前端连接生命周期、触屏组件与命名操作按钮。

## 已修复

1. **触屏复位后无法重新操作。** 旧实现清空了轴值，却保留踏板/摇杆闭包中的手指编号。现在同时重置触点与显示状态，忽略复位前的移动事件，允许新手指接管。真实浏览器测试修复前失败、修复后通过。
2. **快速连点被合并。** 两次短时间点按原先变成长按。现在逐次发送，中间保留中立状态间隔；断开时清空尚未执行的点按。
3. **旧连接事件影响新连接。** 增加连接代次与实例检查，并移除旧监听器；取消连接期间晚到的会话会被释放。异步状态查询与音频结果也不再覆盖新连接界面。
4. **主机响应中断时回收永远等待。** 请求增加总时间上限、响应中断/错误处理和响应大小限制。原测试在响应断开与持续零碎响应两种情形下均超时，修复后正常拒绝并结束等待。
5. **主机离线仍显示就绪、回收结果误判。** 除网页桥接鉴权外，还核对 Sunshine 在线和配对状态；回收检查返回结果及主机是否仍有活动会话。无法确认时阻止新会话并明确报错。
6. **运行中换编码器造成配置与实际不符。** NVIDIA/AMD 切换前要求停止已有 Demo 进程，避免只改文件、实际进程仍使用旧编码器。已验证拒绝切换时配置文件保持不变。
7. **异常请求影响服务稳定性。** WebSocket 地址解析异常改为返回 400，重复信令连接被拒绝，错误 JSON 返回 400；文件读取错误不再成为未处理异常。

## 验证方法

- `node --test tests/*.test.mjs`：会话、HTTP 服务、主机请求、连接生命周期、输入组合与预设回归。
- `/tests/touch.html`：真实浏览器触屏复位、新旧手指切换，只操作测试页。
- `/tests/timers.html`：真实浏览器计时器与按键释放，只操作测试页。
- `node tests/http-live.mjs`：真实主机 HTTP 与心跳回收，已有玩家时跳过会话测试。

测试不能证明项目没有任何剩余缺陷。AMD W7800 硬件实测、长时间弱网、各种车型/模组的自定义绑定仍不在本次验证范围内。
